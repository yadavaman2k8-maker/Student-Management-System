# Student Management System

A responsive student-record dashboard built with HTML, CSS and vanilla JavaScript. Student records are stored in the browser using Local Storage.

## Features
- Add, edit and delete student records
- Search by name, email or course
- Filter by course and active/inactive status
- Dashboard statistics: total students, active students and average marks
- Form validation and duplicate-email prevention
- Responsive layout for desktop and mobile
- Local Storage persistence

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add or edit records. Data is saved in that browser.

No server or package installation is required.

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- Browser Local Storage

## Note
The initial sample records are demo data. Replace or remove them as needed. Local Storage is browser-specific and is not a substitute for a secure production database.
